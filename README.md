# Custom Telegram Bot API Docs

This repository contains the source code for a mobile-friendly version 
of the [Telegram Bot API Documentation](https://core.telegram.org/bots/api). 
It features collapsible sections and a built-in search to help you quickly 
find specific words or phrases by filtering the content.

You can access the docs via the Telegram Mini App: https://t.me/aio3bot/docs

99.9% of the code was written by [JetBrains Junie](https://www.jetbrains.com/junie/). 
I just made a few tweaks and added some prompts. Vibe coding!
